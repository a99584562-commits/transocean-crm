# ТРАНСОУШЕН — система морского страхования грузов

Кастомная демо-CRM для страхового брокера «Трансоушен» (морское страхование зерна/грузов
Азов–Чёрное–Каспий). Вся отраслевая логика работает «из коробки».

Собрано по схеме из Miro (генеральные полисы → сертификаты → премии → убытки + дерево вординга).

## Что внутри (мини-CRM целиком)

| Раздел | Что демонстрирует |
|---|---|
| **Обзор** | KPI портфеля, лента «требует внимания», воронка сертификатов |
| **Ген. полисы** | Kanban-воронка + правило **автопродления** (таймер на 60/30 дней) |
| **Сертификаты** | Автозаполнение из полиса/компании, расчёт **премии**, генерация **документа Ингосстраха** с подстановкой данных (маски) |
| **Суда** | Реестр с авто-расчётом **возраста судна** и подсветкой риска |
| **Премии** | Финансовая воронка: новая → счёт выставлен → оплачен |
| **Убытки** | Claim-флоу с расчётом **франшизы** (ниже → отказ / выше → возмещение) |
| **Подбор вординга** | Интерактивный калькулятор формулировки по морям (АМ/ЧМ/КМ), войне и военным зонам; порог 2,5 → Гигантская + РНПК |

Данные демонстрационные, изменения сохраняются в localStorage. Кнопка **«Сброс»** в шапке
возвращает исходное состояние.

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:5193
```

## Сборка

```bash
npm run build      # → dist/
npm run preview    # локальный просмотр собранной версии
```

## Деплой на GitHub Pages

`base` в `vite.config.js` задан как `'./'` (относительные пути), поэтому сборка работает
в любом подкаталоге Pages без правок.

```bash
# вариант 1 — одной командой (создаст/обновит ветку gh-pages)
npm run deploy

# вариант 2 — вручную
npm run build
npx gh-pages -d dist
```

После деплоя включить Pages: Settings → Pages → Branch: `gh-pages`.

## Стек

Vite + React 18 + Tailwind CSS 3. Без тяжёлых зависимостей: иконки — инлайновые SVG,
drag-and-drop — нативный HTML5, состояние — React Context + localStorage.

## Открытые вопросы со схемы (подсвечены в интерфейсе)

- объём отгрузки ≤ 2,5 млн т — вординг не определён (помечается как требующий андеррайтера);
- контейнерные перевозки — не проработаны;
- разнообразие ставок по ген. полису.
